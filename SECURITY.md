# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it
responsibly by emailing **anthony@etherealogic.com**.

Please do not open a public issue for security vulnerabilities.

## Scope

This repository contains a demonstration of a Databricks intake control pattern.
It does not process real customer data or connect to production systems.
